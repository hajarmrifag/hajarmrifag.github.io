Ledger notes

Amounts are integer pence. A new transfer is HTTP 201 with Idempotency-Replayed false. The same key and the same transfer return HTTP 200, the original id, and Idempotency-Replayed true, without moving money again. A used key with a different amount is HTTP 409 idempotency_conflict. Insufficient funds is HTTP 409 insufficient_funds; the rejection rolls back and does not keep the key. The analytics set of 891,772 records is synthetic and is not this ledger.
