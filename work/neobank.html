Neobank.

01 / Decision

One transfer, one transaction.

Both balance updates commit in one PostgreSQL transaction. Matching idempotency keys are serialized, and account locks are acquired in a consistent order.

The scope covers account balances, transfer history, database-backed tests, container delivery, and analytics across 891,772 synthetic transactions.

02 / Evidence

Retries, conflicts, and a separate question about payoff.

API tests cover retries, conflicting payloads, concurrency, and rollback. The analytics project separates statistical uplift from whether an incentive pays back.

All customer and transaction data is synthetic. This is a portfolio system, not a live banking service.
