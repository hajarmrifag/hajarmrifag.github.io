01 / Decision

Permissions belong in the API.

Status changes are checked on the server, not only hidden in the interface. Document signatures are compared with the declared file type, and each status change is written to an audit trail.

The project scope is a React client and a layered .NET API: authentication, persistence, file validation, and automated checks.

02 / Boundary

The demo does not pretend to be durable storage.

Deployment boundary: uploaded files in the public demo use ephemeral storage. An Azure Blob provider is available for durable storage.
