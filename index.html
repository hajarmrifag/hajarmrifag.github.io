02 · Backend / Application security

Aegis Claims

An insurance claims workflow with authorization, document handling and an audit history.

Submit→Review→Audit

The API enforces role-based transitions and validates uploaded file signatures. React handles forms and remote state; PostgreSQL persists the workflow.

Engineering decisions +

The interface is not a security boundary. Authorization lives in the ASP.NET Core API, with separate domain, application and infrastructure layers.

Make limitations explicit. The public demo uses ephemeral file storage. The repository includes an Azure Blob provider for durable storage, plus a threat model and security assessment.

03 · GPU / Performance engineering

CUDA kernels

Optimize a matrix multiply. Measure it. Find the next bottleneck.

1.28 TFLOPSFP32 GEMM · 1024 × 1024 · NVIDIA T4

From naive memory access to shared-memory and register tiling, guided by Nsight Compute. The final kernel reaches 24% of cuBLAS throughput for the recorded workload.

What the measurements taught me +

Padding reduced excessive shared-memory wavefronts from about 32% to 3% in the profiled kernel. A separate warp-shuffle Softmax experiment was slower than register caching, so the measured winner stayed.
