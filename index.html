04 / BACKEND & DATA SYSTEMS

Neobank API
& analytics

FastAPI · PostgreSQL
SQL · Docker

Source ↗Analytics demo ↗

A transaction API built around atomic transfers and idempotent retries, alongside a reproducible analytics pipeline.

Project scope. Account balances, transfer history, database-backed tests, container delivery and analytics across 891,772 synthetic transactions.

Key decision. Commit both balance updates in one PostgreSQL transaction. Serialize matching idempotency keys and acquire account locks in a consistent order.

Evidence. API tests cover retries, conflicting payloads, concurrency and rollback. The analytics project separates statistical uplift from whether an incentive pays back.

All customer and transaction data is synthetic. This is a portfolio system, not a live banking service.
